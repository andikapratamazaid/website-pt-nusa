# Website PT Nusa Inteligensi Media

Website satu halaman (single-page) PT Nusa Inteligensi Media: studio video AI untuk iklan,
konten media sosial, dan company profile. Tersedia dalam tiga bahasa (Indonesia, English,
Mandarin) dengan tombol pengalih bahasa di halaman.

## Isi Repository

- `index.html` — satu file mandiri berisi seluruh halaman, gaya, dan skrip. Tidak ada file
  pendukung lain yang perlu diunggah.

## Menjalankan

- Lokal: buka `index.html` langsung di peramban.
- Online: aktifkan GitHub Pages (Settings → Pages → Deploy from a branch → main → / (root)).
  Website akan tayang di `https://<username>.github.io/<nama-repository>/`.

## Catatan

Harga dan paket yang tampil di halaman adalah harga uji pasar (lean v2) dan dapat berubah.
Kontak resmi perusahaan di halaman masih perlu disesuaikan dengan nomor dan alamat final.
